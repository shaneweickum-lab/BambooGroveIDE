From six lines to a hexagon

BambooScript reads like Python and moves like a turtle: forward() and turn() drive a pen around the canvas, so a loop becomes a shape almost immediately.

  • No boilerplate — just def setup(): and def draw():
  • for and while both work exactly like you'd expect
  • Swap in the p5.js layer — circle(), noise(), createVector() — whenever you're ready for more
def setup():
    background(20, 20, 20)
    stroke(34, 139, 34)

def draw():
    no_loop()
    for i in range(6):
        forward(120)
        turn(60)
