    Syntax

    def name(params):
    Define a function.
    # comment
    Single-line comment.
    if / elif / else
    Conditionals, Python-style indentation.
    for i in range(n):
    Loop n times, i from 0.
    while cond:
    Loop while cond is true.
    and / or / not
    Boolean operators.
    [1, 2, 3]
    List literal; index with list[0].
    return value
    Return from a function (inside a def only).
    f"hi {name}!"
    f-string: anything inside {'{'}...{'}'} is evaluated and inserted. Use {'{'}{'{'}/{'}'}{'}'} for a literal brace, and {'{'}x:.2f{'}'} to fix a number to 2 decimal places.

    Lifecycle

    def setup():
    Runs once, when the sketch starts.
    def draw():
    Runs once per frame, forever (unless no_loop()).
    no_loop() / loop()
    Stop / resume the draw() loop.
    frame_count / frameCount
    Frames drawn so far.

    Drawing

    background(r, g, b)
    Fill the whole canvas.
    stroke(r, g, b) / fill(r, g, b)
    Set outline / fill color. Also accept a single gray value, or a color() value.
    no_stroke() / no_fill()
    Turn outline / fill off (also noStroke()/noFill()).
    line(x1, y1, x2, y2)
    Straight line between two points.
    rect(x, y, w, h)
    Rectangle. Position meaning depends on rectMode().
    circle(x, y, r)
    Circle centered at (x, y) with radius r.
    ellipse(x, y, w, h)
    Ellipse; position meaning depends on ellipseMode().
    arc(x, y, w, h, start, stop)
    Arc of an ellipse, angles in radians.
    triangle(...) / quad(...)
    3- or 4-point polygon from raw coordinates.
    square(x, y, s)
    Shorthand for rect(x, y, s, s).
    point(x, y)
    A single dot, sized by strokeWeight().
    text(string, x, y)
    Draw text; see textSize()/textAlign()/textFont().

    Turtle movement

    forward(distance)
    Move forward, drawing if the pen is down.
    turn(degrees)
    Rotate heading (clockwise-positive). Aliases: right(), left(-degrees).
    pen_up() / pen_down()
    Stop / resume drawing while moving.
    go_to(x, y)
    Move to an absolute position.
    home()
    Return to the canvas center, heading reset to 0 (up).

    Color

    color(r, g, b, a)
    Build a reusable color value.
    red()/green()/blue()/alpha()
    Read a channel back out of a color() value.
    lerpColor(c1, c2, amt)
    Blend between two colors.
    colorMode("rgb" | "hsb", ...)
    Switch how color channels are interpreted.

    Transform

    push() / pop()
    Save / restore the current style + position/rotation.
    translate(x, y)
    Shift the origin.
    rotate(angle)
    Rotate around the origin, radians.
    scale(x, y)
    Scale subsequent drawing.

    Math

    abs/ceil/floor/round/sq/sqrt/pow
    Basic math.
    sin/cos/tan(angle)
    Trig, angle in radians.
    radians(deg) / degrees(rad)
    Angle unit conversion.
    constrain(n, low, high)
    Clamp a number to a range.
    dist(x1, y1, x2, y2)
    Distance between two points.
    lerp(start, stop, amt)
    Interpolate between two numbers.
    map(v, s1, e1, s2, e2)
    Remap a number from one range to another.
    random() / random(max) / random(min, max)
    Random number; also random(a_list) picks a random item.
    randomSeed(n)
    Make random() repeatable.

    Input & events

    mouse_x / mouse_y (mouseX/mouseY)
    Current mouse position.
    is_pressed() / mouseIsPressed
    Is a mouse button currently down?
    key_pressed / key / keyIsPressed
    Last key, and whether one is currently down.
    def mousePressed():
    Called on mouse-down (also mouseReleased, mouseClicked, mouseMoved, mouseDragged).
    def keyPressed():
    Called on key-down (also keyReleased).

    Terminal tab

    print(value, ...)
    Write a line to the terminal. Works in both Canvas and Terminal mode.
    input(prompt)
    Terminal mode only: pause and wait for the user to type a line.

    Terminal mode runs the same code top-to-bottom as a plain script — no setup()/draw() needed, and canvas-drawing functions aren't available there.

    Modules (multi-file projects)

    import name
    Import a sibling name.bs file; call its functions as name.function().
    from name import fn
    Import one function directly. Add as alias to rename it.

    Use the file chips above the editor to add and switch between files in the same project.

    Curves & custom shapes

    bezier(x1,y1, x2,y2, x3,y3, x4,y4)
    A curved line through two control points.
    beginShape() / vertex(x, y) / endShape(mode)
    Build a custom polygon from any number of points. Pass "close" to endShape to close it into a filled shape.

    Noise

    noise(x, y, z)
    Smooth pseudo-random value (Perlin noise), unlike random() which jumps around.
    noiseDetail(octaves, falloff)
    Adjust noise's texture — more octaves add finer detail.
    noiseSeed(n)
    Make noise() repeatable.

    Vector

    createVector(x, y, z)
    A position/direction with .x/.y/.z.
    v.add(other) / v.sub(other)
    Add/subtract another vector, in place.
    v.mult(n) / v.div(n)
    Scale by a number, in place.
    v.mag() / v.normalize() / v.limit(max)
    Length; scale to length 1; cap the length.
    v.heading() / v.rotate(angle)
    Direction in radians; rotate in place.
    v.dist(other) / v.dot(other)
    Distance to / dot product with another vector.
    v.copy()
    An independent duplicate (methods mutate the original otherwise).

    There's no +/- for vectors (JS has no operator overloading) — use the methods above, the same way real p5.js sketches do.

    Data conversion

    int(v) / float(v)
    Convert a string or boolean to a number.
    str(v)
    Convert anything to text (numbers, True/False, lists).
    boolean(v)
    Convert to True/False using the same rules as if.

    Lists

    len(list)
    Number of items in a list (or characters in a string).
    list.append(value)
    Add value to the end of list, growing it by one.
